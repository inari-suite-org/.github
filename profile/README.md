# Inari Suite

Open-source security tools for FiveM servers. Each tool is named after a part of a shrine, and does one job:
it guards a boundary.

| Tool | What it does | Status |
|---|---|---|
| [**torii**](https://github.com/inari-suite/torii-fx) | Runtime permission firewall for server-side Lua resources | v0.1 alpha |

We write down what each tool does **not** stop, next to what it does. Found a bypass? See each repository's `SECURITY.md`.
